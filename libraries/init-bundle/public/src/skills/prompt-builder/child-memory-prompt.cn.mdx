Child Memory Prompt 编写指南。

**Location**

`app/*/src/**/agt.cn.mdx`（非根目录）

**Structure Fields**

| 字段 | 必需 | 说明 |
|:-----|:-----|:-----|
| 模块背景 | ✓ | 直接开头，无一级标题 |
| 类型 | 可选 | API 接口、数据库层、库函数... |
| Skills | 可选 | 需使用的 skills 及用途 |
| MUST Use MCP Servers | 可选 | 需使用的 MCP 服务及用途 |
| 目录结构 | 可选 | 仅第一层子目录/文件 |

注意：Child 不需要 `# {名称}` 一级标题，直接以模块背景开头。

**Template**

```md
{模块背景}

**Type**
{API 接口 | 数据库层 | 库函数 | ...}

**Skills**
- {skill-name}: {何时使用}

**目录结构**
- `{dir}/`: {说明}
```

**Example**

```md
HTTP 接口层，处理请求路由和响应序列化。

**Type**
API 接口 (Spring WebFlux 6.2)

**Skills**
- api-convention: 接口设计规范

**目录结构**
- `controllers/`: 控制器
- `dto/`: 数据传输对象
```
