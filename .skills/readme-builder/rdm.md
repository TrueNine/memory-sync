# README Builder

This skill writes “human-focused, minimal, mutually exclusive with agt” rdm.cn.mdx with defensive programming (minimal disclosure).

## Three principles

1. **Mutually exclusive with agt**: If sibling agt.cn.mdx exists, its content must not appear in rdm.cn.mdx.
2. **Human-focused, minimal**: Only how to use (run and use); no long prose.
3. **Defensive programming**: Minimal; no full open-source-style docs; no internal or implementation details.

## Usage

Activate when writing or optimising `rdm.cn.mdx`.
