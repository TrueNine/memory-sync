# memory-sync-cli

Prompt synchronisation tool for cross-AI coding tools. One ruleset, multi-target adaptation.

## Quick Start

### Prerequisites

Node.js >= 25.2.1, pnpm >= 10

### Installation

```bash
pnpm add -g @truenine/memory-sync-cli
```

Or use directly:

```bash
npx @truenine/memory-sync-cli
```

### Run

```bash
tnmsc
```

### Update

```bash
pnpm update -g @truenine/memory-sync-cli --latest
```

## GUI Desktop App

The GUI package provides a Tauri desktop app. Build under the `gui/` directory:

```bash
pnpm tauri:build
```
