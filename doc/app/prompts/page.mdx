<div className="prose">
  <h2>概览</h2>
  <p>
    memory-sync 把不同用途的 Prompt 拆分成多种独立的文件类型，以便在多 AI 工具之间重复使用同一套规则。
  </p>

  <h3>主要类型</h3>
  <ul>
    <li><strong>Global Memory</strong>：跨项目、跨会话的长期记忆，例如个人偏好、通用风格。</li>
    <li><strong>Skills</strong>：针对某一类任务的专用技能卡片，例如「写 README」「生成数据库设计」。</li>
    <li><strong>Fast Commands</strong>：短命令或一键操作脚本，适合频繁重复的小任务。</li>
    <li><strong>Sub-agents</strong>：为复杂任务拆分出的子代理配置，每个子代理有独立职责。</li>
    <li><strong>Rules</strong>：与具体项目或目录绑定的规则文件，例如 `.cursor/rules/*.mdx`。</li>
  </ul>

  <p>
    本页给出整体概念，具体写法与风格建议可以参考
    <a href="/prompts/skills">Skills 规范</a> 与
    <a href="/prompts/commands">Fast Commands 规范</a>。
  </p>
</div>
