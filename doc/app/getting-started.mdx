import { Callout } from './components/Callout';

<div className="prose">
  <h2>安装与环境要求</h2>
  <p>
    memory-sync 是一个基于 Node.js 的 CLI + Tauri GUI 工具集，推荐使用
    <code>pnpm</code> 搭配 monorepo 一起管理。
  </p>

  <h3>Node 与包管理器</h3>
  <ul>
    <li>推荐 Node 版本：<code>&gt;= 20.9.0</code></li>
    <li>推荐包管理器：<code>pnpm</code>（与项目 <code>pnpm-workspace.yaml</code> 配套）</li>
  </ul>

  <h2>安装 CLI</h2>
  <p>以下命令展示了典型的全局安装与 npx 使用方式，你可以根据自己的偏好调整：</p>

  ```bash
  # 使用 pnpm 全局安装
  pnpm add -g @truenine/memory-sync

  # 或者通过 npx 临时执行
  npx @truenine/memory-sync@latest --help
  ```

  <h2>初始化规则仓库</h2>

  <Callout type="info">
    建议把「记忆 / 规则仓库」和日常代码仓库分开管理，这样可以在多个项目之间共享同一套 Global
    Memory 与 Skills。
  </Callout>

  <Steps>
    <Step title="创建目录并进入">
      例如 <code>~/aindex</code> 或你习惯的任意路径。
    </Step>
    <Step title="运行初始化命令">
      执行 <code>tnmsc init</code>（或未来提供的类似命令），生成示例配置与 Prompt 文件。
    </Step>
    <Step title="打开并修改示例文件">
      编辑 <code>tnmsc.example.json</code> 与 <code>app/global.src.mdx</code>，根据自己的工作流调整内容。
    </Step>
  </Steps>

  <p>
    更具体的配置字段说明见 <a href="/config">配置文件说明</a>，规则写法见
    <a href="/prompts">Prompt 规则与结构</a>。
  </p>
</div>
