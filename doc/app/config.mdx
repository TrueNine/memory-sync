  <h2>配置文件位置与示例来源</h2>
  <p>
    本页基于初始化模板 <code>tnmsc.example.json</code> 展开说明，该文件通常由
    <code>tnmsc init</code> 生成，并作为你个人配置的起点。
  </p>

  <h2>基础字段</h2>

  <h3>version</h3>
  <p>
    使用 CalVer 风格的版本号，例如：
    <code>2026.10218.12101</code>。建议与项目发布版本保持一致，方便排查问题。
  </p>

  <h3>workspaceDir</h3>
  <p>
    工作区根目录，支持 <code>~</code> 展开，例如：
  </p>

  ```json
  {
    "workspaceDir": "~/project"
  }
  ```

  <h2>aindex 配置</h2>
  <p>
    <code>aindex</code> 描述了一套 Aindex 目录结构，用于统一管理 Skills、Commands、Agents、Rules 以及 Global Memory 等文件。
  </p>

  ```json
  {
    "aindex": {
      "name": "aindex",
      "skill": { "src": "src/skills", "dist": "dist/skills" },
      "command": { "src": "src/commands", "dist": "dist/commands" },
      "subAgent": { "src": "src/agents", "dist": "dist/agents" },
      "rule": { "src": "src/rules", "dist": "dist/rules" },
      "globalMemory": {
        "src": "app/global.src.mdx",
        "dist": "dist/global.mdx"
      },
      "workspaceMemory": {
        "src": "app/workspace.src.mdx",
        "dist": "dist/app/workspace.mdx"
      },
      "project": { "src": "app", "dist": "dist/app" }
    }
  }
  ```

  <p>推荐保持上述结构不变，仅在确有需要时调整路径。</p>

  <h2>profile 字段</h2>

  ```json
  {
    "profile": {
      "name": "Your Name",
      "username": "your_username",
      "gender": "male",
      "birthday": "1990-01-01"
    }
  }
  ```

  <p>
    这些信息通常用于在 Global Memory 或 Skills 中做变量替换，避免多处手写姓名/昵称等个人信息。
  </p>

    后续页面会进一步介绍不同类型 Prompt 文件的写法，详见

  </p>
