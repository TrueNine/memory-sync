# 文档总览

这套文档站围绕当前仓库事实组织，目标是帮助你快速建立正确的使用路径、概念模型和配置边界。

## 从哪里开始

- 第一次使用 `memory-sync`，从 [快速上手](/docs/quick-start) 开始，先把安装、工作区准备和第一次同步跑通。
- 需要理解为什么仓库转向 Rust-first / NAPI-first，以及哪些文件才是源内容，进入 [概念与世界观](/docs/concepts)。
- 已经开始维护 prompts、skills、commands、sub-agents 或 rules，直接查看 [内容编写](/docs/authoring)。
- 需要确认字段名、CLI 行为、Schema 或输出边界时，优先使用 [参考手册](/docs/reference)。
- 已在日常使用中，需要 dry-run、clean、升级或排障信息时，查看 [运维与排障](/docs/operations)。

## 文档边界

- 文档以仓库当前可验证实现为准，不把未落地的自动化、页面或工作流写成既成事实。
- 当前公开文档以中文为权威版本；命令、API 名称和关键术语保持英文。
- 如果 README、旧页面和当前实现冲突，这里优先跟随 `tnmsc --help`、Schema、目录结构和实际代码。
