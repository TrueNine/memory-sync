# 文档总览

这套文档从头重建，目标只有一个：让你基于仓库真相快速进入使用，而不是继续绕在过时的示例页面里。

## 你在这里能拿到什么

| 方向 | 解决的问题 | 入口 |
| --- | --- | --- |
| 快速上手 | 怎么装、怎么放置 aindex、怎么做第一次同步 | [快速上手](/docs/quick-start) |
| 概念与世界观 | 这个工具为什么存在、架构怎么切分、什么才是“真源” | [概念与世界观](/docs/concepts) |
| 内容编写 | 怎么写 prompts、skills、commands、sub-agents、rules | [内容编写](/docs/authoring) |
| 参考手册 | `plugin.config.ts`、CLI、Schema、输出范围、清理保护 | [参考手册](/docs/reference) |
| 运维与排障 | `dry-run` / `clean`、故障排查、升级注意事项 | [运维与排障](/docs/operations) |

## 建议阅读顺序

1. 先看 [快速上手](/docs/quick-start)，确认你不是沿着旧的 `tnmsc init` 惯性在操作。
2. 再看 [架构](/docs/concepts/architecture) 和 [单一真源模型](/docs/concepts/source-of-truth)，明确哪些文件是源、哪些只是输出。
3. 开始编写内容前，阅读 [全局与工作区 Prompt](/docs/authoring/global-and-workspace-prompts) 和 [Skills](/docs/authoring/skills)。
4. 遇到具体配置或行为边界时，直接跳到 [参考手册](/docs/reference)。

## 当前文档的边界

- 本仓库当前没有已落地的 docs 自动部署流水线，所以这里不会把自动部署写成既成事实。
- 当前公开文档语言以中文为唯一权威版本，后续如果扩展英文，应基于这套结构继续加，而不是重新拆一次。
- 命令行为以真实 `tnmsc --help`、Schema 和实现代码为准；如果 README 与旧页面有冲突，这里优先跟实现对齐。
