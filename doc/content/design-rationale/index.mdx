# 设计初衷

这一节只处理“为什么这样做”，不承担安装、命令、Schema 或页面工作流说明。

## 为什么要单独分出来

因为背景叙事一旦和操作文档混在一起，会同时伤害两件事：

- 用户很难快速进入最短使用路径
- 维护者很容易把理念页写进功能页，导致 IA 再次失焦
