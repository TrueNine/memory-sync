# 参考手册

## 什么时候直接来这里

- 你需要确认 `plugin.config.ts` 或 front matter 的字段名和含义。
- 你需要核对 `tnmsc` 当前公开的命令表面和行为边界。
- 你需要知道哪些输出目标、清理保护和范围控制已经落地。
