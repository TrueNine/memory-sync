# 概念与世界观

这一节不负责安装步骤，而是帮助你建立项目的核心心智模型，避免把输出文件、兼容层或旧工作流误当成当前架构中心。

## 这一节回答什么问题

1. 哪些文件是源内容，哪些只是派生输出。
2. 为什么仓库明确转向 Rust-first / NAPI-first，而不是继续堆纯 TypeScript 兼容层。
3. 同步为什么必须显式建模写入目标、清理范围和边界控制。

- [单一真源模型](/docs/concepts/source-of-truth)：明确 `.src.mdx`、MDX 与输出文件之间的关系。
- [同步管线](/docs/concepts/pipeline)：理解插件如何声明目标文件、生成流程与清理行为。
