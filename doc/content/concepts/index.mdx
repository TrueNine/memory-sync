# 概念与世界观

这一节不讲“怎么点按钮”，而是讲三个更根的问题：

1. 为什么这个项目不把任何单一 AI 工具当成你的长期家园。
2. 为什么仓库明确转向 Rust-first / NAPI-first，而不是继续往 TypeScript 里叠兼容层。
3. 为什么同步必须可计算、可输出、可清理，而不是复制粘贴一堆提示词。
