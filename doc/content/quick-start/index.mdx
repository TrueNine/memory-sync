# 快速上手

这一节面向第一次使用 `memory-sync` 的读者，目标是先把一次真实同步流程跑通，再回头补充概念和参考细节。

## 这一节解决什么问题

- 确认运行前提、安装方式和 CLI 入口。
- 准备全局配置、aindex 目录与目标项目配置。
- 通过 `tnmsc dry-run` 先验证输出范围，再执行第一次同步。

## 建议顺序

1. 阅读 [安装与前提](/docs/quick-start/install)，先确认 Node、Rust 与当前分发方式都满足要求。
2. 阅读 [工作区与 aindex](/docs/quick-start/workspace-setup)，按当前仓库支持的目录结构准备输入源。
3. 阅读 [第一次同步](/docs/quick-start/first-sync)，先执行 `dry-run`，再执行真实写入。
4. 如果你来自旧版本或旧文档体系，再补充 [从旧文档迁移](/docs/quick-start/migration)。
