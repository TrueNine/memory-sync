# 快速上手

如果你只想先把 `memory-sync` 跑起来，不想先看长篇世界观，这一节就是你的入口。

## 最短路径

1. 安装 CLI。
2. 准备全局配置文件 `~/.aindex/.tnmsc.json`。
3. 准备一个 aindex 目录，把 prompts / skills / commands / sub-agents / rules 放到约定路径。
4. 在目标项目根目录提供 `plugin.config.ts`。
5. 先执行 `tnmsc dry-run`，确认目标文件列表没跑偏。
6. 再执行默认同步命令或后续清理命令。
