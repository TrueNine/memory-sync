# 从旧文档迁移

## 旧站最容易误导你的地方

### 1. 平铺 `app/*.mdx` 页面并不是真正的文档信息架构

旧 `doc/` 站点在 App Router 下只真正构建出了 `/` 与 `/prompts`，其他平铺 MDX 页面并没有形成对应的可访问路由。这次已经重构为：

- 首页：`/`
- 文档命名空间：`/docs/*`

### 2. `tnmsc init` 不再负责初始化 aindex

当前实现会直接返回废弃提示：

```text
`tnmsc init` is deprecated and no longer initializes aindex.
```

如果你还在按旧文档期待它生成模板，那不是你操作错了，而是旧文档已经落后于当前实现。

### 3. “部署到 Vercel 已完成” 是错误叙述

仓库的工作流注释明确指出 docs auto-deployment 仍是 placeholder。新文档已经删除这类既成事实式表述。

## 迁移建议

1. 把旧收藏链接改到 `/docs` 下面的新页面。
2. 把所有“初始化靠 `tnmsc init`”的团队内部说明删掉。
3. 以后用本仓库文档页 + `tnmsc --help` + Schema 三者交叉验证，不再依赖旧截图或旧 Landing Page 文案。
