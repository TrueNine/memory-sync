# 工作区与 aindex

## 全局配置文件在哪里

`tnmsc config` 明确写入的目标是：

```text
~/.aindex/.tnmsc.json
```

这份文件是全局配置入口，不是项目内的本地副本。

## 当前默认 aindex 结构

`cli/src/config.ts` 中的默认值显示，当前默认目录布局是：

```text
aindex/
├─ skills/              -> dist/skills
├─ commands/            -> dist/commands
├─ subagents/           -> dist/subagents
├─ rules/               -> dist/rules
├─ app/
│  ├─ global.src.mdx    -> dist/global.mdx
│  └─ workspace.src.mdx -> dist/workspace.mdx
├─ ext/                 -> dist/ext
└─ arch/                -> dist/arch
```

注意两点：

1. 代码默认目录名是 `subagents`，不是旧文档里常写的 `subAgents` 路径名。
2. 配置字段仍然使用 `aindex.subAgents.src/dist` 这样的 camelCase 键名，这是配置层与文件系统层的区分，不要混掉。

## 示例全局配置

仓库内的 `cli/src/config/example.json` 对当前字段有一个较完整的示例：

```json
{
  "version": "2026.10218.12101",
  "workspaceDir": "~/project",
  "aindex": {
    "skills": { "src": "skills", "dist": "dist/skills" },
    "commands": { "src": "commands", "dist": "dist/commands" },
    "subAgents": { "src": "agents", "dist": "dist/agents" },
    "rules": { "src": "rules", "dist": "dist/rules" },
    "globalPrompt": { "src": "app/global.src.mdx", "dist": "dist/global.mdx" },
    "workspacePrompt": { "src": "app/workspace.src.mdx", "dist": "dist/workspace.mdx" }
  },
  "logLevel": "info"
}
```

## `plugin.config.ts` 在项目里做什么

项目根目录的 `plugin.config.ts` 是运行期装配输出插件和最终管线的地方。当前默认插件清单包括：

- `AgentsOutputPlugin`
- `ClaudeCodeCLIOutputPlugin`
- `CodexCLIOutputPlugin`
- `GeminiCLIOutputPlugin`
- `CursorOutputPlugin`
- `WindsurfOutputPlugin`
- `WarpIDEOutputPlugin`
- `JetBrainsAIAssistantCodexOutputPlugin`
- `ReadmeMdConfigFileOutputPlugin`

以及若干 IDE / ignore / code style 输出插件。

详细说明见 [plugin.config.ts 参考](/docs/reference/plugin-config)。
