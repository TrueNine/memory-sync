# Quick Install

If you just want to get the CLI installed first, use your preferred package manager:

<PackageManagerTabs
  commands={{
    npm: 'npm install -g @truenine/memory-sync-cli',
    pnpm: 'pnpm add -g @truenine/memory-sync-cli',
    yarn: 'yarn global add @truenine/memory-sync-cli'
  }}
/>

Then confirm that the command works:
Then confirm that the command works:

```sh
tnmsc help
```

You should see `dry-run`, `clean`, and `config`, and `init` should already be marked as deprecated.

## Local Monorepo Development

If you are developing inside this monorepo, use:

```sh
pnpm install
pnpm -C cli exec node dist/index.mjs --help
```

> [!warning]
> `pnpm` is the only recommended package manager for local development right now.
