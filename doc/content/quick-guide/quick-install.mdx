# 快速安装

如果你现在只想先把 CLI 装起来，按你常用的包管理器执行：

<PackageManagerTabs
  commands={{
    npm: 'npm install -g @truenine/memory-sync-cli',
    pnpm: 'pnpm add -g @truenine/memory-sync-cli',
    yarn: 'yarn global add @truenine/memory-sync-cli'
  }}
/>

然后确认命令可用：

```sh
tnmsc help
```

你应该看到 `dry-run`、`clean` 与 `config`，同时看到 `init` 已经是 deprecated。

## monorepo 本地开发

如果你是在这个 monorepo 里本地开发，改用：

```sh
pnpm install
pnpm -C cli exec node dist/index.mjs --help
```

> [!warning]
> 目前仅推荐使用 pnpm 进行开发
