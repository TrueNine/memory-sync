# 快速安装

如果你只是想先把 CLI 装上，直接安装主包：

```sh
npm install -g @truenine/croessweave-cli
```

当前主包会自动为受支持的平台拉取对应的 native 子包。已覆盖的平台组合是 Linux x64/arm64 (glibc)、macOS x64/arm64 和 Windows x64。Linux musl 或 Alpine 目前还不在 npm 二进制支持范围内。

然后确认命令可以正常工作：

```sh
tnmsc help
```

你应该能看到 `install`、`dry-run`、`clean` 和 `plugins`。

## 本地 monorepo 开发

如果你正在这个 monorepo 内开发，请使用：

```sh
pnpm install
pnpm -C cli run build
./target/release/tnmsc --help
```

> [!warning]
> 当前本地开发唯一推荐的包管理器是 `pnpm`。
