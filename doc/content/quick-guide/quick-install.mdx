# 快速安装

如果你只是想先把 CLI 装上，直接使用你偏好的包管理器：

请直接安装与你平台匹配的 native CLI 包：

- Linux x64 (glibc): `@truenine/memory-sync-cli-linux-x64-gnu`
- Linux arm64 (glibc): `@truenine/memory-sync-cli-linux-arm64-gnu`
- macOS arm64: `@truenine/memory-sync-cli-darwin-arm64`
- macOS x64: `@truenine/memory-sync-cli-darwin-x64`
- Windows x64: `@truenine/memory-sync-cli-win32-x64-msvc`

然后确认命令可以正常工作：

```sh
tnmsc help
```

你应该能看到 `install`、`dry-run`、`clean` 和 `plugins`。

## 本地 monorepo 开发

如果你正在这个 monorepo 内开发，请使用：

```sh
pnpm install
pnpm -C cli run build
./target/release/tnmsc --help
```

> [!warning]
> 当前本地开发唯一推荐的包管理器是 `pnpm`。
