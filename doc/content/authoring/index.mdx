# 内容编写

这一节说明你应该维护哪些输入资产，以及它们在同步前分别承担什么职责。

## 这一节解决什么问题

- 区分全局 Prompt 与工作区 Prompt 的作用域和职责。
- 区分 skills、commands、sub-agents、rules 等输入集合的边界。
- 明确这些输入如何经由输出插件写入不同目标工具。
